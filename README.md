## What is this???

It is a 2D arcade game built in **Godot**. Catch falling tacos and get combo streaks to upgrade your stats and unlock new  cool sombreros.

---

## Features

*  **Special Tacos** – Catch standard, Golden, Frozen, Spicy tacos and mini game tacos .

*  **Combo Multipliers** – Chain consecutive catches to boost payouts ($2\times$, $3\times$).

*  **Shop Upgrades** – Increase bag capacity, movement speed, and special taco spawn rates.

*  **Cool Sombreros** - Buy bag upgrades to get them

*  **Mini Games** - A platformer game (reallyy fun trust me)
